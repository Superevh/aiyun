How Lift Apps were built

One person, AI, and a lot of feedback

Lift Apps is an experiment in what a single builder can ship with AI as a team-mate. Every app goes through the same loop, and you can be part of it.

  1. Start from a real team problemRetros that drag, estimates anchored by the loudest voice, roadmaps that go stale.
  2. Build it with AI, fastDesign, code and review with AI, then test it with real teams.
  3. ListenEvery page has a Feedback button. I read every note.
  4. Ship the change, every weekRelease notes list what changed and why.
